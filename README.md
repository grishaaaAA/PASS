# PASS - нарядка автобусов и водителей

Сервис планирования выхода автобусов и водителей в наряды для ГУП «Пассажиравтотранс».

## Что уже есть

| Часть | Где | Что делает |
|---|---|---|
| Постоянная часть | `naryad/data/city.py` | Строит город по вводным: парки, маршруты, наряды, смены, автобусы, водители |
| Меняющаяся часть | `naryad/data/days.py` | День за днём: поломки и ТО, график 4 / 2, отпуска, больничные, медосмотр |
| Запуск и сводка | `naryad/data/generate.py` | Один день или серия дней подряд |
| Проверка данных | `naryad/data/check.py` | Ловит противоречия до того, как данные попадут в движок |
| CSV | `naryad/data/csvio.py` | Выгрузка в CSV и загрузка обратно в JSON |
| Настройки | `naryad/data/presets.py` | `case` - вводные заказчика, `park7` - парк №7 по справке на 12.05.2026 |
| Формат данных | `docs/CONTRACT.md` | Описание всех полей |
| Образцы | `data/samples/` | Город по вводным кейса (1 день), парк №7 (будни и выходной, JSON и CSV) |

Нужен только Python 3.10+, сторонних библиотек нет.

## Запуск

```
python -m naryad.data.generate                                   # 1 день по вводным кейса
python -m naryad.data.generate --days 30 --out series/           # 30 дней подряд
python -m naryad.data.generate --parks 3 --release 250 --routes 50 --mix 700,700,500
python -m naryad.data.generate --preset park7 --out park7.json --csv park7_csv
python -m unittest
```

| Параметр | Что значит |
|---|---|
| `--date` | Первый день: суббота и воскресенье - выходные |
| `--days` | Сколько дней подряд; каждый день - файл `days/ГГГГ-ММ-ДД.json`, плюс сводка `series.csv` |
| `--seed` | Номер набора: одинаковый номер даёт одинаковые данные |
| `--moment` | `morning` - утро дня (медосмотр идёт), `plan` - план на завтра |
| `--parks`, `--release`, `--routes`, `--mix` | Вводные: число парков, выпуск парка, маршрутов всего, классы средний / большой / особо большой |
| `--readiness`, `--weekend` | Тех. готовность и выпуск выходного дня от будней |
