# PASS - нарядка автобусов и водителей

Сервис планирования выхода автобусов и водителей в наряды для ГУП «Пассажиравтотранс».

## Что уже есть

| Часть | Где | Что делает |
|---|---|---|
| Генератор данных | `naryad/data/generate.py` | Собирает парк: маршруты, наряды, смены, автобусы, водители |
| Проверка данных | `naryad/data/check.py` | Ловит противоречия до того, как данные попадут в движок |
| CSV | `naryad/data/csvio.py` | Выгрузка в CSV и загрузка обратно в JSON |
| Настройки парков | `naryad/data/presets.py` | Парк №7 по справке на 12.05.2026 |
| Формат данных | `docs/CONTRACT.md` | Описание всех полей |
| Образцы | `data/samples/` | Парк №7: будни и выходной, JSON и CSV |

Нужен только Python 3.10+, сторонних библиотек нет.

## Запуск

```
python -m naryad.data.generate --date 2026-10-05 --seed 1 --out park.json --csv park_csv
python -m unittest
```

| Параметр | Что значит |
|---|---|
| `--date` | Дата: суббота и воскресенье дают выходной день |
| `--seed` | Номер набора: одинаковый номер даёт одинаковые данные |
| `--moment plan` | План на завтра: медосмотр ещё не проходили |
| `--moment morning` | Утро дня: у большинства медосмотр пройден, у части нет |
