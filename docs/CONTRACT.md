# Формат данных, версия 0.1

Общий язык генератора, движка и интерфейса. Меняется только по согласию обоих (Григорий и Антон).

Набор данных - один JSON-файл. Движок читает только JSON. CSV загружается через `naryad.data.csvio.read_csv`, превращается в такой же набор и проходит ту же проверку.

```
{
  "meta":     {...},
  "parks":    [...],
  "routes":   [...],
  "duties":   [...],   наряды (выходы)
  "shifts":   [...],   смены внутри нарядов
  "vehicles": [...],
  "drivers":  [...]
}
```

Время записывается как `ЧЧ:ММ` от начала суток. После полуночи часы идут дальше 24: `25:10` - это 01:10 следующего дня.

## Кто что заполняет

| Что | Кто |
|---|---|
| Исправен / неисправен, график водителя, медосмотр | Генератор (в жизни - парк) |
| Какой автобус и водитель на каком наряде | **Движок** |
| Группы «на маршруте / резерв / исправен в парке / неисправен» | Считаются из плана движка, показывает интерфейс |

Генератор никогда не ставит автобус на наряд: иначе движку нечего решать.

## meta

| Поле | Пример | Что это |
|---|---|---|
| format_version | `"0.1"` | Версия этого описания |
| preset | `"park7"` | Настройка генератора |
| seed | `1` | Номер набора: одинаковый номер даёт одинаковые данные |
| date | `"2026-10-05"` | Дата дня |
| day_type | `"weekday"` / `"weekend"` | Будни или выходной |
| moment | `"plan"` / `"morning"` | План на завтра или утро дня |
| source, assumptions | | Откуда цифры и что додумано |

## parks - парки

| Поле | Пример | Что это |
|---|---|---|
| id | `"P07"` | Номер парка |
| name | `"Автобусный парк №7"` | |
| address, lat, lon | `null` | Адрес и координаты, могут быть пустыми |
| state | `"working"` | `working` работает, `emergency` ЧП, `down` выведен из строя |
| list_count | `420` | Автобусов по документам. Сверяется со списком автобусов, расхождение - ошибка |

## Проверка

`naryad.data.check.check(data)` возвращает `{"errors": [...], "warnings": [...]}`.

- **Ошибка** - данные противоречат сами себе (повтор номера, ссылка в никуда, смены не встык, список автобусов не сходится с `list_count`). Движку такие данные не отдаём.
- **Предупреждение** - данные целы, но расходятся с планом или не хватает автобусов либо водителей. Это рабочая ситуация, её и решает движок.
