## 5. Накопленные предпочтения Антона (в дополнение к правилам в CLAUDE.md)

- Никакого сленга: «нарядка», «движок», «идут в работу» - нельзя (проверка - grep из CLAUDE.md).
- Меньше слов, никаких пояснительных абзацев и микро-комментариев; уведомлений «всё хорошо» не нужно - только проблемы.
- Числа - с подписью внутри карточки; главное число крупнее, «из N» мельче.
- Ничего полупрозрачного (кроме недоступного и свечения): насыщенный цвет + белый текст.
- Крестик - простой тёмный на белом; второстепенные кнопки без градиента; логотип ни с чем не совмещать.
- Анимации мягкие, везде, без резких стартов; ничего не «прыгает» и не мигает.
- Не перерисовывать элемент под курсором; рамка одной толщины.
- Перед правкой UI - загрузить дизайн-скиллы (список в CLAUDE.md).

```
python3.12 -m unittest                      # 438 тестов
grep -rn "арядк\|идут в работу\|идёт в работу\|в бой\|[Дд]вижок" naryad/web/dispatcher   # тексты
```
Пройти путь: заставка → приветствие → выбор парков → подготовка → «Рассчитать» → карта, проблемы, наряды. Тестовые отметки и расчёты после проверки стирать из `data/marks.sqlite` (таблицы `marks`, `journal`, `runs`, и `sqlite_sequence` для `runs`).
