# Вариант Б «Пульт» - в архиве

Прототип рабочего места диспетчера от 07.10.2026: шаги «Загрузка → Проверка → Нарядка», рабочий стол с вкладками «Сводка», «Маршруты», «Наряды», «События», карта и панель «Почему так» справа. Выбран вариант А «Карта» (`naryad/web/dispatcher/app`), этот оставлен как источник идей: карточки «Требует внимания», таблица проверки по паркам до расчёта, таблица маршрутов с фильтрами.

Запустить для сравнения: скопировать папку в `naryad/web/dispatcher/b` и в `naryad/web/dispatcher.py` вернуть выбор папки (`Handler.variant`). Общая часть (`common/`) у вариантов одна, поэтому со временем архивная копия может разойтись с ней.
