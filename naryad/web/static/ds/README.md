# Дизайн-система AUTODISP - локальная копия для страниц сервиса

- `tokens.css`, `bundle.css`, `bundle.js`, `logo.svg`, `mark.svg` - из дизайн-системы AUTODISP (версия от 02.10.2026, с исправлениями подъёма карточек и фокуса строк таблицы).
- `fonts/Ubuntu-*.ttf` - шрифт Ubuntu © Canonical Ltd., Ubuntu Font Licence 1.0 (свободное распространение).
- Coolvetica (Typodermic) сюда не входит: условия её распространения в коде не проверены. Без неё главные заголовки набираются Ubuntu, логотип - кривыми в SVG и от шрифта не зависит.

При обновлении дизайн-системы заменить эти файлы целиком; пути к шрифтам в `tokens.css` - локальные (`fonts/...`).
